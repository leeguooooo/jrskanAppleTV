JRKAN Apple TV MVP

面向实体 Apple TV 的原生 tvOS 赛事观看应用；macOS 不在产品范围内。

界面

截图取自 Apple TV 4K 模拟器实拍。播放页为全屏 AVPlayerViewController， 带原生传输栏、LIVE 指示与 Info 面板；因画面内嵌第三方推广，此处不附播放截图。 资源与合成脚本见 assets/brand/，上架准备见 docs/app-store-submission.html。

首版能力

能力实现
比赛列表读取目标站点公开首页与动态列表脚本
浏览第 1 步选择比赛，第 2 步读取并选择具体频道，例如“中文高清 Q ⑤”
播放解析公开 iframe 与加密播放器链路，发现 HLS 后交给 AVPlayer
平台tvOS 17+；最终验收设备为实体 Apple TV

生成、测试与构建

xcodegen generate
xcodebuild -project JRKANApple.xcodeproj -scheme JRKANTV \
  -destination 'platform=tvOS Simulator,name=Apple TV 4K (3rd generation)' test
xcodebuild -project JRKANApple.xcodeproj -scheme JRKANTV \
  -sdk appletvos -configuration Release build CODE_SIGNING_ALLOWED=NO
模拟器测试和成功生成 IPA 都不等于真机验收。完成标准是：安装到指定实体 Apple TV， 用遥控器打开应用、加载比赛列表、进入赛事并确认至少一条公开线路开始播放。

边界

应用只读取公开页面，不托管或重分发视频，不绕过登录、DRM、付费墙或地域限制。 线路由第三方维护，可能随时失效。公开发布前必须确认赛事内容授权、品牌使用权与隐私合规。

当前为了兼容第三方 HTTP 页面启用了宽松网络策略。正式发布前应由自有 HTTPS 后端完成解析，并收紧 App Transport Security。
